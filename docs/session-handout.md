# Foothold: one page for whoever is running the session

Print this, or forward it. It assumes you have never written Python and do not
intend to start today.

**The site:** https://jbtk-cell.github.io/foothold/

Nothing to install, no logins, no accounts. Open it and go. If the room's
internet is unreliable, open the site on each machine once beforehand, because
after the first load it works offline.

## What the students are doing

Reading a short lesson, then writing a few lines of Python in the box below it
and pressing Run. The site checks their answer by actually running it, so any
working answer passes, including one nobody anticipated.

## When a student is stuck

Go in this order. It works even though you do not know the answer.

1. **"Read the error out loud."** Python says which line broke and why.
   Beginners skip it because it looks like noise. Half of all stuckness is a
   message nobody read.

2. **"Take the first hint."** Every exercise has three, getting more specific.
   One at a time, try again in between.

3. **"Press Show me why."** This replays their program line by line with the
   variables shown next to it. Drag the slider together and look for a value
   that is not what they expected. You can ask "should that be zero there?"
   without knowing any Python, and that question is usually the whole fix.

4. **Ask a neighbour.** Someone else's eyes find a typo faster.

5. **Show the solution.** Every lesson has one. Better a student who copies it,
   understands it, and keeps going than a student who quits. Do not save it for
   the deserving.

## Things that will happen

**Lesson one will be the hardest one all day.** It asks them to print exact
text, and the capital letters and the exclamation mark have to match. Expect
typos. Tell them in advance that computers are fussy and this is the lesson
that teaches it.

**Someone will freeze the page with a loop.** It is a normal mistake and it
gets stopped automatically after ten seconds. Nothing breaks, nothing is lost.
Say so before it happens so the first student to do it does not panic.

**Indentation will confuse people.** In Python the spaces at the start of a
line change what the code means. It is a real rule, not a typo.

## At the end

If the computers are shared or wipe themselves overnight, have students press
Export on the home page and keep the small file, or just note the lesson name
they reached. Progress is stored on that machine and in that browser only.

## The one thing worth reporting back

Where students got stuck, especially if it was for a silly reason. That is hard
information to get and it is what improves the course. Open an issue at
github.com/jbtk-cell/foothold or pass it to whoever gave you this page.
