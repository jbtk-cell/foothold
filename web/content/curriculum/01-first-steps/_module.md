---
title: First Steps
summary: Run your first program, read your first error, and stop being afraid of the terminal.
---

Every programmer alive has sat where you are sitting now, looking at a blank
editor, wondering what on earth to type. This module gets you past that in
about twenty minutes.

You will write code that runs. You will also write code that breaks, on
purpose, because reading an error message is a skill and the sooner you start
the better.
