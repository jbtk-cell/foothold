`if` runs a block of code only when a condition is `True`.

```python
temperature = 31

if temperature > 25:
    print("It is hot")

print("Done")
```

Two pieces of punctuation matter:

The **colon** at the end of the `if` line. Forget it and you get a
`SyntaxError`.

The **indentation** underneath. Those four spaces are not decoration - they
are how Python knows which lines belong to the `if`. In many languages that
job is done by curly braces; in Python it is done by whitespace, which means
your code cannot look different from what it does.

In the example, `print("Done")` is not indented, so it is outside the `if` and
runs either way. Change the temperature to 10 and run it: you get `Done` and
nothing else.

## The block can be several lines

Everything at the same indentation belongs to the same block.

```python
balance = -20

if balance < 0:
    print("You are overdrawn")
    print("A fee of 5 has been added")
    balance = balance - 5

print(balance)
```

## Indentation is not optional

```python
if True:
print("nope")
```

That is an `IndentationError`. Python is telling you it expected a block and
found nothing. Four spaces is the convention; be consistent, and let the
editor's Tab key put them in for you.

## Your turn

Complete the program so that it prints a warning when the tank is low.

If `fuel` is below 15, print exactly:

```
Warning: low fuel
```

Whatever the fuel level, always finish by printing:

```
Fuel: 8
```

with the real number in it.

```python starter
fuel = 8

# Print the warning only when fuel is below 15.

print(f"Fuel: {fuel}")
```

```python solution
fuel = 8

if fuel < 15:
    print("Warning: low fuel")

print(f"Fuel: {fuel}")
```

```python tests
def test_warns_when_low():
    """It warns when the fuel is low"""
    expect_output("Warning: low fuel\nFuel: 8")

def test_uses_if():
    """The warning is inside an if"""
    assert "if " in SOURCE, (
        "Use an `if` so the warning only appears when the fuel is actually low."
    )

def test_condition_reads_the_variable():
    """The condition tests the fuel variable"""
    condition = SOURCE.split("if ", 1)[-1].split(":", 1)[0]
    assert "fuel" in condition, (
        "The condition should compare `fuel` against 15, so the program still "
        "behaves correctly if the fuel level changes."
    )
    assert "15" in condition, "Compare the fuel against 15."
```
